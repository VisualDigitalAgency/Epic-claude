The problem
01 Claude Code forgets your architecture between sessions.
02 You re-explain the same decisions over and over.
03 epic fixes that. Once. Permanently.
How it works

Four commands.
Complete architecture.

STEP 01
epic plan "..."
Clarify Requirements
Targeted questions about scale, database, auth, and deployment. Infers what it can — never asks twice.
STEP 02
epic tech confirm
Confirm Your Stack
Proposes a full tech stack with rationale and alternatives. You confirm or adjust individual decisions.
STEP 03
epic generate
Generate Artifacts
5 architecture artifacts generated and validated through 3 gates before anything touches disk.
STEP 04
epic sync
Sync to CLAUDE.md
Architecture context written into your project. Claude Code reads it automatically. Every session.
What gets synced

Claude Code always knows what you're building.

Every sync writes a managed section into your CLAUDE.md. Claude Code reads it automatically at session start — full architectural context, no re-explaining.

▸
Managed section only Content outside the markers is never touched, never read, never deleted.
▸
Backup before every write Timestamped backups with 30-day retention. epic sync --rollback restores instantly.
▸
Manual edit detection epic detects if you edited inside the managed section and prompts before overwriting.
